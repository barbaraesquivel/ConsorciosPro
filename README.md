Consorcios Pro

Aplicación de escritorio (C# / .NET, WinForms) para la gestión de reclamos de mantenimiento y la priorización de temas de asamblea en consorcios. Permite cargar y clasificar reclamos, buscar proveedores por categoría según precio, rapidez o eficiencia histórica, calcular la imputación de costos, y priorizar qué problemas recurrentes conviene llevar como tema a la próxima asamblea.

Requisitos
Windows 10 (64 bits) o superior
.NET (versión LTS)
SQL Server / SQL Server Express o equivalente
4 GB RAM mínimo
Cómo ejecutarlo
Abrí el .sln en Visual Studio.
Restaurá los paquetes NuGet.
Configurá la cadena de conexión en App.config.
F5 para compilar y correr.
