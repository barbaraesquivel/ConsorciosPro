Tutorial de contingencia: SQL Server para Consorcios Pro

Esta guia sirve cuando el instalador no encuentra SQL Server, no puede conectarse o no puede crear la base de datos AppBaseDB. Funciona sin conexion a Internet y se puede imprimir.

1. Que necesita Consorcios Pro

  • Una instancia de SQL Server (2016 o posterior; Express alcanza) en ejecucion.
  • Un usuario de Windows con permiso para crear la base (o una base vacia AppBaseDB creada por el encargado, con ese usuario como db_owner).
  • La aplicacion usa autenticacion de Windows: no hay usuario ni contrasena de SQL.

2. Que opcion me conviene

SituacionQue hacer
El equipo ya tiene SQL Server (lo habitual en la sala)En el instalador elija la instancia de la lista o escriba su nombre (ver seccion 4).
No hay SQL Server y tiene permisos de administradorInstale SQL Server LocalDB (seccion 3) o SQL Server Express (seccion 5).
No hay SQL Server y no es administradorPida al encargado que instale SQL Server Express, o use otra PC.

3. Opcion rapida: SQL Server LocalDB

  1. En el instalador, en la pagina Servidor de base de datos, presione Instalar SQL Server LocalDB (aparece solo si el instalador lo incluye).
  2. Windows pedira permiso de administrador solo para ese paso. Acepte y espere a que termine.
  3. El servidor queda seleccionado como (localdb)\MSSQLLocalDB.
Importante: LocalDB es privado de cada usuario de Windows. La base queda en el perfil del usuario que instalo; otro usuario del equipo no vera esos datos.

Si el instalador no lo incluye, bajelo del sitio de Microsoft (busque «SQL Server 2022 Express LocalDB») e instalelo con el archivo SqlLocalDB.msi.

4. Como saber el nombre de la instancia

  1. Presione Windows + R, escriba services.msc y Enter.
  2. Busque servicios que empiecen con SQL Server (...). El texto entre parentesis es el nombre de la instancia.
ServicioNombre a escribir en el instalador
SQL Server (SQLEXPRESS).\SQLEXPRESS (tambien localhost\SQLEXPRESS)
SQL Server (MSSQLSERVER). o localhost
SQL Server (otro nombre).\otro_nombre

Si el estado del servicio es Detenido, clic derecho → Iniciar (el instalador tambien lo intenta, pero en una PC compartida puede no tener permiso).

5. Instalar SQL Server Express (requiere administrador)

  1. Descargue SQL Server 2022 Express desde microsoft.com (busque «SQL Server Express descargar»).
  2. Ejecute el instalador y elija el tipo Basica. Acepte la licencia y la carpeta por defecto.
  3. Al terminar, anote el nombre de la instancia que muestra (normalmente SQLEXPRESS).
  4. Vuelva a ejecutar el instalador de Consorcios Pro y use .\SQLEXPRESS.

6. Problemas frecuentes

Mensaje o sintomaCausa probable y solucion
No se pudo conectar con el servidorNombre mal escrito o servicio detenido. Revise la seccion 4. Si el servidor esta en otra PC, pruebe con su nombre completo.
El usuario no puede crear bases de datosPida al encargado que cree una base vacia llamada AppBaseDB y agregue su usuario de Windows como db_owner. Luego vuelva a ejecutar el instalador: solo carga las tablas y los datos.
La base AppBaseDB ya existe pero esta desactualizada o incompletaSi es una base de prueba: en SSMS (o con sqlcmd) ejecute DROP DATABASE AppBaseDB y vuelva a instalar. El instalador hizo antes un backup en la carpeta de backups de la instancia.
El servicio esta detenido y no puedo iniciarloPida a un administrador que lo inicie desde services.msc.
Error «El nombre de objeto PROPUESTA_ASAMBLEA no es valido» al abrir la aplicacionLa base se creo con una version vieja del script. Borre la base de prueba y reinstale.
Cambie de servidor despues de instalarEdite Configuracion_413BE.txt (carpeta de instalacion) y corrija la linea Servidor=.... No hace falta reinstalar.

7. Crear la base a mano (ultimo recurso)

El script esta en la carpeta de instalacion, dentro de BaseDeDatos\AppBaseDB_Instalacion_Sala.sql. Con SQL Server Management Studio: abra el archivo, conectese a la instancia y presione Ejecutar. Por linea de comandos:

sqlcmd -S .\SQLEXPRESS -E -f 65001 -i "AppBaseDB_Instalacion_Sala.sql"
Despues, configure Servidor=.\SQLEXPRESS en Configuracion_413BE.txt y abra la aplicacion.

8. Donde estan los registros

  • Registro del instalador de la base: Documentos\ConsorciosPro_instalacion.log
  • Instalacion de LocalDB (si se uso): lo informa el propio instalador de Windows.

Si pide ayuda, adjunte ese archivo: indica el servidor usado, el paso que fallo y el mensaje de SQL Server.
